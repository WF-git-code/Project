# C++ 高性能固定式线程池

一个基于**C++11 标准**实现的生产级固定式线程池，采用固定工作线程 + 有界任务队列架构，专为任务量稳定的高并发场景设计。完全兼容 C++11 及以上所有标准，无需任何第三方依赖。

## 项目简介

本项目实现了一个工业级标准的固定式线程池，解决了传统单线程和多线程编程中频繁创建销毁线程的性能开销问题。线程池启动时一次性创建指定数量的工作线程，所有任务统一放入有界队列中调度执行，在保证高吞吐量的同时实现了资源的精确控制。

## 核心技术亮点

### 1. 极简高效的架构设计

- **固定线程数量**：启动时一次性创建所有工作线程，运行期间无动态伸缩开销，性能更稳定
- **有界阻塞队列**：严格限制任务队列最大长度，防止任务无限堆积导致内存溢出
- **无锁原子状态**：使用 std::atomic 管理线程池运行状态，避免不必要的锁竞争
- **批量任务支持**：支持一次性取出队列中所有任务，大幅减少锁竞争次数

### 2. 现代 C++ 特性深度应用

- **完美转发**：Submit 函数支持任意签名的函数和任意数量的参数，返回 std::future 获取结果
- **移动语义**：全程使用 std::move 避免任务对象拷贝，实现任务传递零拷贝
- **智能指针**：使用 std::unique_ptr 管理线程对象，自动释放资源，无内存泄漏
- **RAII 设计**：析构函数自动调用 Stop ()，确保资源正确释放，防止资源泄漏

### 3. 健壮的任务处理机制

- **优雅降级策略**：当任务队列满且入队超时时，提交任务的线程直接执行该任务，保证任务绝不丢失
- **超时入队机制**：支持任务入队超时等待，避免提交线程长时间阻塞
- **虚假唤醒防护**：所有条件变量等待均在 while 循环中检查条件，符合并发编程最佳实践
- **异常安全**：任务执行过程中的异常不会导致线程池崩溃，异常会传递到 future 对象中

### 4. 安全的生命周期管理

- **优雅关闭**：Stop () 方法先等待队列中所有任务执行完成，再回收工作线程
- **一次性关闭保证**：使用 std::call_once 确保停止逻辑只被执行一次，避免重复关闭问题
- **死锁预防**：所有锁的获取顺序一致，条件变量通知时机精准
- **线程安全接口**：所有对外接口都是线程安全的，支持多线程并发提交任务

## 设计思路与决策

### 为什么选择固定式线程池？

- **对比缓存式线程池**：固定式线程池无动态创建销毁线程的开销，在任务量稳定的场景下性能更高，延迟更稳定
- **对比无界线程池**：固定式线程池严格限制最大并发数，避免高并发下系统资源耗尽
- **对比单线程**：充分利用多核 CPU 的计算能力，大幅提高任务处理吞吐量
- **固定式优势**：资源可控、性能稳定、实现简单、易于调试，是大多数业务场景的最佳选择

### 关键设计决策

1. **线程池启动时一次性创建所有线程**：避免运行时创建线程的开销，保证响应速度
2. **使用有界任务队列**：防止任务无限堆积导致内存溢出，同时起到限流作用
3. **队列满时由调用线程执行任务**：这是一种优雅的降级策略，既保证任务不丢失，又能对系统进行限流
4. **分离任务队列实现**：将任务队列封装为独立的模板类，提高代码复用性和可测试性
5. **先停止队列再停止线程**：优雅关闭时先停止队列接受新任务，等待所有任务执行完成后再停止线程，确保任务不丢失

## 使用示例

### 基本使用

```c++
#include "FixedThreadPool.hpp"
#include <iostream>
#include <future>

int main() {
    // 创建线程池：队列大小1000，入队超时100微秒，工作线程8个
    FixedThreadPool pool(1000, 100, 8);

    // 提交无返回值任务
    pool.Excute([]() {
        std::cout << "Hello from thread pool!" << std::endl;
    });

    // 提交带返回值任务
    auto future = pool.Submit([](int a, int b) {
        return a + b;
    }, 10, 20);

    // 获取结果
    std::cout << "Result: " << future.get() << std::endl;

    // 优雅关闭线程池
    pool.Stop();
    return 0;
}
```

### 批量任务提交

```c++
#include "FixedThreadPool.hpp"
#include <iostream>
#include <vector>
#include <future>

int main() {
    FixedThreadPool pool(1000, 100, 8);

    // 提交1000个任务
    std::vector<std::future<int>> futures;
    for (int i = 0; i < 1000; ++i) {
        futures.push_back(pool.Submit([i]() {
            return i * i;
        }));
    }

    // 获取所有结果
    int sum = 0;
    for (auto& fut : futures) {
        sum += fut.get();
    }

    std::cout << "Sum of squares: " << sum << std::endl;

    pool.Stop();
    return 0;
}
```
