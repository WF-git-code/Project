# 日志清理工具使用说明

## 功能概述

日志清理工具会自动删除指定天数之前的日志文件，防止日志文件占用过多磁盘空间。

## 配置项说明

在 `my.conf` 配置文件中添加了以下日志清理配置：

```ini
#日志清理配置
#是否启用日志清理(0:禁用, 1:启用)
enablelogclean 1
#日志保留天数
logkeepdays 7
#日志文件目录
logdir ./
```

### 配置参数详解

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| enablelogclean | int | 1 | 是否启用日志清理（0=禁用，1=启用） |
| logkeepdays | int | 7 | 保留日志的天数 |
| logdir | string | ./ | 日志文件所在目录 |

## 核心类

### LogCleaner 类

**位置**: `server/LogFile/include/LogCleaner.hpp`

**主要功能**:
- 自动清理超过指定天数的日志文件
- 支持定时清理（每小时检查一次）
- 支持回调函数，记录删除的文件

**构造函数**:
```cpp
LogCleaner(const std::string& log_dir, int keep_days = 7)
```

**主要方法**:
- `start()` - 启动定时清理线程
- `stop()` - 停止清理线程
- `clean()` - 执行一次清理
- `cleanNow()` - 立即清理，不启动线程
- `setCallback()` - 设置删除文件时的回调函数

**使用示例**:
```cpp
#include "LogCleaner.hpp"

int main() {
    // 创建清理器，保留7天日志
    logfile::LogCleaner cleaner("/var/log/server", 7);
    
    // 设置删除回调
    cleaner.setCallback([](const std::string& file) {
        std::cout << "已删除: " << file << std::endl;
    });
    
    // 启动定时清理
    cleaner.start();
    
    // 主程序继续运行...
    
    // 程序结束时停止
    cleaner.stop();
    
    return 0;
}
```

## LoggerManager 集成

LoggerManager 已经集成了日志清理功能，并根据配置文件自动启用/禁用：

```cpp
// 从配置文件读取后初始化
logfile::LoggerManager::getInstance().init(
    "server",              // 日志文件基础名
    conf.log_keep_days,    // 保留天数
    conf.log_dir,          // 日志目录
    conf.enable_log_clean == 1  // 是否启用
);

// 启动日志系统（包括日志清理）
logfile::LoggerManager::getInstance().start();

// 手动触发清理
logfile::LoggerManager::getInstance().cleanLogs();

// 停止
logfile::LoggerManager::getInstance().stop();
```

## 工作原理

1. **启动时**: 
   - 读取配置文件中的日志清理参数
   - 如果 `enablelogclean=1`，自动启动 LogCleaner
   - LogCleaner 每小时检查一次

2. **运行时**: 
   - 后台线程自动清理超过 `logkeepdays` 天的日志
   - 删除前会调用回调函数记录

3. **停止时**: 
   - 自动停止清理线程
   - 刷出日志缓冲区

4. **判断依据**: 
   - 根据文件修改时间（st_mtime）
   - 只删除 `.log` 后缀的文件

## 注意事项

- 默认保留7天日志
- 只删除 `.log` 后缀的文件
- 清理操作在独立线程中进行，不影响主线程
- 删除前会调用回调函数，可用于记录日志
- 可以通过配置完全禁用日志清理功能
