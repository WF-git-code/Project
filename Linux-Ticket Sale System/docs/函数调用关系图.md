## 3. ConnectSocket连接处理

**文件**：`server.cpp#L757`

### 3.1 ConnectSocket::Handle_Data()

```
ConnectSocket::Handle_Data()
│
├─> 获取命令类型
│
└─> switch(cmd) {
        case CMD_LOGIN:
        │   └─> ConnectSocket::User_Login()
        │       ├─> Send_Jsonobj()
        │       ├─> MysqlClient::Db_User_Login()
        │       └─> Send_OK() / Send_ERR()
        │
        case CMD_REGISTER:
        │   └─> ConnectSocket::User_Register()
        │       ├─> Send_Jsonobj()
        │       ├─> MysqlClient::Db_User_Register()
        │       └─> Send_OK() / Send_ERR()
        │
        case CMD_SHOW_TICKET:
        │   └─> ConnectSocket::Show_Ticket()
        │       ├─> Cache_Get_Ticket_List()
        │       │   └─> RedisConnectionPool::Get()
        │       │
        │       ├─> if(缓存未命中)
        │       │   └─> MysqlClient::Db_Show_Ticket()
        │       │       └─> Cache_Set_Ticket_List()
        │       │
        │       └─> Send_Jsonobj()
        │
        case CMD_ORDER:
        │   └─> ConnectSocket::Yd_Ticket()
        │       ├─> Redis_Lock()              [分布式锁]
        │       │   └─> RedisConnectionPool::Get()
        │       │
        │       ├─> MysqlClient::Db_Yd_Ticket()
        │       │   ├─> MysqlConnectionPool::GetConnection()
        │       │   ├─> mysql_query("BEGIN")
        │       │   ├─> mysql_query("UPDATE...")
        │       │   ├─> mysql_query("INSERT...")
        │       │   └─> mysql_query("COMMIT")
        │       │
        │       ├─> Cache_Delete_Ticket_List()  [清除缓存]
        │       │
        │       └─> Redis_Unlock()              [释放锁]
        │
        case CMD_SHOW_ORDER:
        │   └─> ConnectSocket::Show_My_Yuyue()
        │       ├─> Send_Jsonobj()
        │       ├─> MysqlClient::Db_Get_Yuyue()
        │       └─> Send_OK() / Send_ERR()
        │
        case CMD_CANCEL:
        │   └─> ConnectSocket::Cancel_Yuyue()
        │       ├─> Send_Jsonobj()
        │       ├─> MysqlClient::Db_Cancel_Yuyue()
        │       └─> Send_OK() / Send_ERR()
        │
        case CMD_FILE_START:
        │   └─> ConnectSocket::File_Start()
        │       └─> open(), lseek()
        │
        case CMD_FILE_CHUNK:
        │   └─> ConnectSocket::File_Chunk()
        │       └─> write()
        │
        case CMD_FILE_END:
        │   └─> ConnectSocket::File_End()
        │       └─> close()
        │
        case CMD_FILE_CHECK:
        │   └─> ConnectSocket::File_Check()
        │       └─> stat()
        │
        case CMD_EXIT:
        │   └─> 关闭连接
        │
        default:
            └─> Send_ERR()
    }

## 7. 线程池

**文件**：`ThreadPool/CachedThreadPool.hpp`

### 7.1 CachedThreadPool构造函数

```
CachedThreadPool()
│
└─> Start(core_threads)
    ├─> Running = true
    ├─> 创建core_threads个核心线程
    │   └─> std::thread(&CachedThreadPool::Running_Thread, this)
    │       └─> 每个线程执行Running_Thread()
    │
    └─> All_ThreadSize += core_threads
```

### 7.2 CachedThreadPool::AddTask()

```
CachedThreadPool::AddTask(Task task)
│
├─> TaskList.Add(task)            [TaskQueue.hpp]
│   ├─> 如果队列满
│   │   └─> 等待
│   │
│   └─> 如果有空闲线程
│       └─> 直接唤醒一个线程
│
└─> 如果没有空闲线程且未达到最大线程数
    └─> 创建非核心线程
        ├─> std::thread(...)
        └─> Diltation_Thread_Pool[thread_id] = thread
```

### 7.3 CachedThreadPool::Running_Thread()

```
CachedThreadPool::Running_Thread()
│
├─> while(Running) {
│       │
│       ├─> TaskList.Take(task)   [阻塞获取任务]
│       │
│       ├─> if(task && Running) {
│       │       task()            [执行任务]
│       │   }
│       │
│       └─> 如果是非核心线程且队列空
│           └─> 检查空闲时间
│               ├─> 如果超时
│               │   └─> detach()并退出
│               └─> 如果未超时
│                   └─> 继续等待
│       }
│   }
```

## 9. 文件上传

**文件**：`server.cpp`, `client.cpp`

### 9.1 客户端上传流程

```
TcpClient::Upload_File()
│
├─> get_file_size()              [获取文件大小]
│
├─> Send_Request(CMD_FILE_CHECK, {filename})
│   └─> 接收响应
│       └─> 获取已上传的offset
│
├─> Send_Request(CMD_FILE_START, {filename, file_size})
│   └─> 服务器打开文件, 定位到offset
│
├─> 循环读取并发送文件块
│   │
│   ├─> open(file)
│   │
│   ├─> lseek(offset)            [定位到断点]
│   │
│   └─> while(offset < file_size) {
│           read(chunk, 8KB)
│           Send_Request(CMD_FILE_CHUNK, {offset, data})
│           offset += chunk_size
│       }
│
└─> Send_Request(CMD_FILE_END)
    └─> 服务器关闭文件
```

### 9.2 服务器端接收

```

└─> lseek(SEEK_END)              [支持断点续传]

ConnectSocket::File_Chunk()       [server.cpp#L970]

├─> 验证offset
└─> 返回确认

ConnectSocket::File_End()         [server.cpp#L1008]

## 12. 关键设计模式总结

### 12.1 Reactor模式

```
┌────────────┐
│   Epoll    │  主线程：监听事件
│   Wait     │
└─────┬──────┘
      │
      │ 有事件就绪
      ▼
┌────────────┐
│  Thread    │  分发到线程池
│   Pool     │
└─────┬──────┘
      │
      │ 取任务
      ▼
┌────────────┐
│  Worker    │  处理业务逻辑
│   Thread   │
└────────────┘
```

### 12.2 单例模式

```
MysqlConnectionPool::getInstance()    // 全局唯一实例
RedisConnectionPool::getInstance()    // 全局唯一实例
LoggerManager::getInstance()         // 全局唯一实例
```

### 12.3 RAII模式

```
ConnectionGuard guard;  // 构造函数：获取连接
// 业务逻辑
// 无论正常还是异常，析构函数都会归还连接
```

### 12.4 生产者-消费者模式

```
┌─────────────┐     任务队列     ┌─────────────┐
│   Epoll     │  ─────────────> │   Worker    │
│   线程       │                 │   线程       │
│  (生产者)   │                 │  (消费者)   │
└─────────────┘                 └─────────────┘
```

### 12.5 分布式锁模式

```
SET key value NX PX timeout_ms    // 获取锁
GET key                           // 检查锁值
DEL key                           // 释放锁(仅当锁值匹配)
```

## 13. 错误处理机制

### 13.1 异常情况处理

```
1. 数据库连接失败
   └─> Logger日志记录
   └─> 返回错误码

2. Redis连接失败
   └─> 降级到MySQL直接查询
   └─> Logger日志记录

3. 事务失败
   └─> 自动ROLLBACK
   └─> 释放分布式锁
   └─> 返回错误码

4. 网络断开
   └─> Epoll检测到断开事件
   └─> 清理连接资源
   └─> 归还连接到池

5. 任务队列满
   └─> 等待或拒绝新任务
   └─> Logger日志记录
```

## 14. 性能优化点

### 14.1 连接池复用

```
传统方式：
连接 → 查询 → 关闭连接
      ↓
每次都要：TCP三次握手 + MySQL认证

连接池方式：
从池中取连接 → 查询 → 归还到池
      ↓
复用已有连接，避免频繁创建销毁
```

### 14.2 Redis缓存

```
无缓存：
查询MySQL → 每次都要磁盘IO

有缓存：
查询Redis → 命中则直接返回
        → 未命中则查MySQL并存入Redis
```

### 14.3 乐观锁防超卖

```
UPDATE ticket_table
SET tk_count = tk_count + 1
WHERE tk_id = ? AND tk_count < tk_max
        │
        └─> affected_rows=0时说明票已售完
```

### 14.4 异步日志

```
同步日志：
写日志 → 等待磁盘IO完成

异步日志：
写日志 → 放入缓冲区 → 后台线程批量写磁盘
```
