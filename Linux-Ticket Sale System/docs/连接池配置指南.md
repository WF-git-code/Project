# 连接池配置指南

---

## 📋 概述

本项目包含两个连接池：
1. **MySQL连接池** - 管理数据库连接
2. **Redis连接池** - 管理缓存连接

两者均采用 **LRU（最近最少使用）** 算法优化连接管理，支持自动清理失效连接。

---

## 🎯 配置文件说明

配置文件位置：`my.conf`

### 完整配置示例

```conf
# ==================== 网络配置 ====================
ip 127.0.0.1              # 监听IP地址
port 6000                 # 监听端口
lismax 1024               # 最大监听队列长度

# ==================== 线程池配置 ====================
corethreadnum 4           # 核心线程数（常驻线程）
maxthreadnum 17           # 最大线程数（核心+扩展）
taskmax 1024              # 任务队列最大长度
taskwaittime 10           # 任务等待时间（微秒）
threadwaittime 10         # 线程空闲超时时间（秒）

# ==================== MySQL连接池配置 ====================
dbhost 127.0.0.1          # MySQL主机地址
dbport 3306               # MySQL端口
dbname epoll_project      # 数据库名称
dbuser root               # 数据库用户名
dbpassword 211929         # 数据库密码
dbpoolsize 8              # MySQL连接池大小

# ==================== Redis连接池配置 ====================
redishost 127.0.0.1       # Redis主机地址
redisport 6379            # Redis端口
redispassword             # Redis密码（空表示无密码）
redispoolsize 4           # Redis连接池大小
redisttl 300              # 缓存过期时间（秒）

# ==================== 日志配置 ====================
enablelogclean 1          # 是否启用日志清理
logkeepdays 7             # 日志保留天数
logdir ./                 # 日志存储目录
```

## 🚀 MySQL连接池配置

### 配置参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `dbhost` | 127.0.0.1 | MySQL服务器地址 |
| `dbport` | 3306 | MySQL端口 |
| `dbname` | epoll_project | 数据库名称 |
| `dbuser` | root | 数据库用户名 |
| `dbpassword` | 211929 | 数据库密码 |
| `dbpoolsize` | 8 | 连接池大小（建议值：CPU核心数 * 2） |

### 连接池大小建议

| 场景 | 建议连接池大小 | 说明 |
|------|--------------|------|
| 开发环境 | 4-8 | 低并发场景 |
| 测试环境 | 8-16 | 中等并发场景 |
| 生产环境 | 16-32 | 高并发场景 |

**计算公式**：`connections = min(CPU核心数 * 2, 最大并发数)`

### LRU算法原理

MySQL连接池使用LRU（最近最少使用）算法管理连接：

```
┌─────────────────────────────────────────────────────────────┐
│                   LRU连接池工作原理                         │
├─────────────────────────────────────────────────────────────┤
│                                                           │
│  连接链表结构（最近使用的在头部）                            │
│  ┌──────┬──────┬──────┬──────┬──────┐                     │
│  │ conn1│ conn2│ conn3│ conn4│ conn5│                     │
│  │(最近) │      │      │      │(最远)│                     │
│  └──────┴──────┴──────┴──────┴──────┘                     │
│                                                           │
│  获取连接时：                                              │
│  1. 遍历链表找到第一个空闲连接                              │
│  2. 将其移动到链表头部（标记为最近使用）                     │
│  3. 返回该连接                                             │
│                                                           │
│  归还连接时：                                              │
│  1. 检查连接有效性（ping测试）                              │
│  2. 有效：放到链表头部                                     │
│  3. 无效：丢弃并创建新连接补充                              │
│                                                           │
└─────────────────────────────────────────────────────────────┘
```

### 连接有效性检查

连接池会自动检测并清理无效连接：

1. **获取连接时**：检查连接状态，无效则跳过
2. **归还连接时**：使用 `mysql_ping()` 检测连接有效性
3. **定期清理**：获取连接时自动清理无效连接

## 🚀 Redis连接池配置

### 配置参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `redishost` | 127.0.0.1 | Redis服务器地址 |
| `redisport` | 6379 | Redis端口 |
| `redispassword` | 空 | Redis密码（无密码则留空） |
| `redispoolsize` | 4 | Redis连接池大小 |
| `redisttl` | 300 | 缓存过期时间（秒） |

### Redis连接池特性

| 特性 | 说明 |
|------|------|
| LRU算法 | 优先复用最近使用的连接 |
| 自动清理 | 检测无效连接并自动补充 |
| 分布式锁 | 支持SET NX PX实现分布式锁 |
| 缓存管理 | 支持TTL自动过期 |

## 🔧 性能调优建议

### MySQL连接池调优

```conf
# 高并发场景建议配置
dbpoolsize 16             # 增加连接池大小
```

### Redis连接池调优

```conf
# 高缓存命中率场景
redispoolsize 8           # 增加连接池大小
redisttl 600             # 延长缓存过期时间
```

### 线程池与连接池配合

```
线程池最大线程数 >= MySQL连接池大小 + Redis连接池大小
```

例如：
- MySQL连接池：8
- Redis连接池：4
- 线程池最大线程数：建议 >= 17（预留额外线程处理IO）

## 🛠️ 故障排查

### MySQL连接问题

**常见错误**：
```
MySQL connect error: Can't connect to MySQL server on '127.0.0.1' (111)
```

**排查步骤**：
1. 检查MySQL服务是否启动
2. 检查MySQL端口是否正确（默认3306）
3. 检查防火墙是否允许访问
4. 检查用户名密码是否正确

### Redis连接问题

**常见错误**：
```
Redis connect error: Connection refused
```

**排查步骤**：
1. 检查Redis服务是否启动
2. 检查Redis端口是否正确（默认6379）
3. 检查Redis是否设置了密码
4. 检查Redis bind配置（建议绑定127.0.0.1）

## 💡 注意事项

1. **连接池大小不要过大**：过多连接会增加数据库负担
2. **定期监控**：关注连接池使用情况
3. **密码安全**：生产环境不要硬编码密码，使用环境变量
4. **备份配置**：定期备份配置文件
