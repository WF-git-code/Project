##  配置示例速查

具体配置请看docs目录下具体配置文档，以及全局MyConf.txt配置文件，会在编译时复制一份文件到bin目录，bin目录配置文件是无效的。

### 如何运行？

c/c++ 环境 linux Ubuntu20.4包

注意redis配置和MySQL配置

数据库 版本 说明 Redis 5.0.7 hiredis 5.2.1       MySQL 8.0.42 Ubuntu 20.04 包

```bash
cd build 
make clean
make
cd ../bin
./server
./client
```

### 核心技术亮点

| 技术点               | 说明                                 | 为什么重要                  |
| -------------------- | ------------------------------------ | --------------------------- |
| Epoll + EPOLLONESHOT | 高效I/O多路复用，保证线程安全        | 高并发场景必备              |
| 缓存式线程池         | 核心线程常驻，非核心线程动态扩容回收 | 高峰低峰自适应              |
| MySQL连接池          | 复用连接，减少握手开销               | 数据库操作性能提升10倍+     |
| Redis连接池          | 复用Redis连接，支持缓存和分布式锁    | 缓存命中率提升，锁竞争降低  |
| 票务信息缓存         | Redis缓存ticket:list，TTL=300秒      | 减少数据库查询，QPS提升5倍+ |
| 分布式锁             | SET NX PX实现，防止超卖              | 高并发预约场景核心保障      |
| 缓存一致性           | 先更新数据库再删缓存                 | 保证数据准确性              |
| 双缓冲异步日志       | 前台线程写内存，后台线程写磁盘       | 不阻塞业务，延迟低          |
| 事务 + 乐观锁        | 保证数据一致性，防止超卖             | 预约系统核心                |
| RAII智能管理         | Socket/Connection自动释放            | 避免资源泄露                |

### 启动流程详解

```
┌─────────────────────────────────────────────────────────────────────┐
│ Step 1: 解析命令行参数                                               │
│         支持指定配置文件路径（默认 ../my.conf）                     │
└────────────────────────────────────┬────────────────────────────────┘
                                     │
┌────────────────────────────────────▼────────────────────────────────┐
│ Step 2: 加载配置文件                                                 │
│         读取 my.conf，初始化 ServerConfig 类                        │
│         包括：IP/端口、线程池参数、数据库配置、日志配置、Redis配置   │
└────────────────────────────────────┬────────────────────────────────┘
                                     │
┌────────────────────────────────────▼────────────────────────────────┐
│ Step 3: 初始化日志系统                                               │
│         LoggerManager::init(...)                                    │
│         LoggerManager::start()      (启动后台线程)                  │
│         LoggerManager::setOutput()  (设置输出回调)                  │
└────────────────────────────────────┬────────────────────────────────┘
                                     │
┌────────────────────────────────────▼────────────────────────────────┐
│ Step 4: 初始化MySQL连接池                                            │
│         MysqlConnectionPool::getInstance().init(...)                │
│         预创建 db_pool_size(默认8) 个连接                          │
└────────────────────────────────────┬────────────────────────────────┘
                                     │
┌────────────────────────────────────▼────────────────────────────────┐
│ Step 5: 初始化Redis连接池                                            │
│         RedisConnectionPool::getInstance().init(...)                │
│         预创建 redis_pool_size(默认4) 个连接                        │
│         支持缓存和分布式锁功能                                      │
└────────────────────────────────────┬────────────────────────────────┘
                                     │
┌────────────────────────────────────▼────────────────────────────────┐
│ Step 6: 创建TCP服务器对象                                            │
│         TcpServer ser(conf)                                          │
└────────────────────────────────────┬────────────────────────────────┘
                                     │
┌────────────────────────────────────▼────────────────────────────────┐
│ Step 7: 初始化服务器                                                 │
│         ser.Ser_Init()                                              │
│         ├─ 创建Socket: socket()                                     │
│         ├─ 设置端口复用: setsockopt(SO_REUSEADDR)                   │
│         ├─ 绑定地址: bind()                                         │
│         ├─ 开始监听: listen()                                       │
│         ├─ 创建Epoll: epoll_create()                                │
│         └─ 注册监听Socket: epoll_ctl(EPOLL_CTL_ADD)                 │
└────────────────────────────────────┬────────────────────────────────┘
                                     │
┌────────────────────────────────────▼────────────────────────────────┐
│ Step 8: 进入主事件循环（永不退出）                                   │
│         ser.Run()                                                    │
│         while(true) {                                               │
│             epoll_wait(...)        // 等待事件                      │
│             do_events()             // 处理事件                      │
│         }                                                          │
└─────────────────────────────────────────────────────────────────────┘
```
